# India Unboxed — Website Prototype

A colourful multi-page HTML/CSS/JS prototype based on the Group 5 business plan.

## Pages
- `index.html` — Home
- `products.html` — Shop with search/filter
- `regions.html` — Regional discovery
- `gifts.html` — Discovery/festive gift boxes
- `stories.html` — Regional storytelling
- `about.html` — Business/value proposition
- `contact.html` — Enquiry form
- `cart.html` — Demo cart using localStorage

## Run locally
Just open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders while preserving the structure.
3. Go to Settings → Pages.
4. Choose Deploy from branch → `main` → `/root`.
5. Open the generated GitHub Pages URL.

## Hostinger
For the prototype, upload the project files to `public_html`.

For a real e-commerce launch, connect a backend/e-commerce platform for:
- product/inventory management
- customer accounts
- orders
- payments
- shipping
- admin dashboard

The business plan identifies WordPress + WooCommerce as the planned platform.
